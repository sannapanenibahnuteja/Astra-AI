# Bob 0.10.24 — plain black, reliable controls

- Plain black workspace, sidebar and status background. Background gradients and grid removed; dark cards and existing core motion retained.
- Footer Settings icon is a real accessible button. Navigation has accessible labels and tooltips.
- Voice can upgrade an in-progress single-command capture to hands-free instead of doing nothing.
- Read aloud restores its state after output errors and prevents overlapping manual playback. Explicit Read aloud / Test voice output work with automatic replies disabled.
- App filtering ignores case and surrounding spaces. Ctrl+/ focuses the composer after returning from another page.
- Voice catalog refresh shows load failures. Phone pairing/revocation buttons cannot overlap their operations; an invalid saved address gives useful feedback.

## Try it

Quit the older Bob through its tray menu and launch this folder's Bob.exe with _internal beside it. Click the footer Settings icon, turn off automatic voice replies and save, then use Test voice output. Send What time is it? and use Read aloud. In Capabilities filter with CALC and check Calculator remains visible. During single-command listening, press Voice to keep the conversation going, then End voice. Test the starter cards, New conversation, Memory save/remove and settings save normally.
