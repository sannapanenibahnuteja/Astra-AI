# Bob 0.10.23 — futuristic, approachable desktop

- Deep navy surfaces with cyan and violet accents, subtle spatial background and luminous panel borders.
- A compact holographic Bob core replaces the plain welcome tile. Its glow reflects listening/speaking state. Orbital rings rotate slowly, the core breathes gently, and panels enter smoothly. Listening and speaking adjust the pulse. Motion pauses in the background and is disabled with reduced-motion preferences.
- New welcome copy and clearer starter cards keep everyday tasks within reach.
- Brighter text, navigation selection and keyboard focus preserve readability. Voice remains beside the message box, with compact and wide layouts retained.
- Settings, Memory, Capabilities and conversation surfaces use the same visual language.

## Try it

Quit the old Bob from its tray menu and launch this folder's `Bob.exe` with `_internal` beside it. Review the four navigation destinations, resize the window and try a starter card: it fills the message box for review before sending. Type **What time is it?**, or use **Voice** and speak after Listening. Use **End voice** to finish.

This is an appearance update. Windows action, speech and phone capabilities are unchanged. See [complete manual](USER-MANUAL.md) and [verification](TEST-REPORT-0.10.23.md).
