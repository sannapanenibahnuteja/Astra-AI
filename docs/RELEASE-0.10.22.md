# Bob 0.10.22 — a quieter desktop

The desktop now uses charcoal surfaces, a restrained mint accent, simpler typography and a compact Bob mark. Decorative HUD rings and the welcome animation are hidden. The welcome cards show practical examples; the layout fits ordinary laptop windows without hiding the bottom row.

A Voice / End voice button beside the composer gives direct access to hands-free conversation when the status side panel is hidden. Memory, Capabilities and Settings share the same surfaces and typography. Narrow windows retain icon navigation and New conversation. Keyboard focus remains visible; reduced motion disables card hover movement.

Command execution, recognition and phone services retain their existing behavior. This release does not add new backend capabilities.

## Try the update

1. Quit the previous Bob through its tray menu. Launch `Bob.exe` from this release folder with `_internal` beside it.
2. Inspect Assistant, Memory, Capabilities and Settings. Resize the window and check that the composer remains reachable.
3. Type **What time is it?**. Check a reply appears. Press **Voice**, speak after Listening, then use **End voice** to stop the session.
4. Tab through the controls and check the mint focus outline. Open New conversation to return to the starter cards.
