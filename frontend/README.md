# ⚡ Astra OS

> An extensible AI operating system for conversation, knowledge, automation and productivity.

---

## ✨ Overview

Astra OS is a modern AI desktop assistant built with a modular architecture.

Instead of being only a chatbot, Astra is designed as an AI platform that combines:

- 🤖 Conversational AI
- 🎙️ Voice Assistant
- 🌐 AI Browser
- 📄 Document Intelligence
- 🧠 Long-Term Memory
- 🤖 AI Agents
- 🖥️ Desktop Automation

---

## 🚀 Features

### ✅ AI Chat

- Streaming responses
- Markdown rendering
- Syntax highlighting
- Conversation history

### 🎤 Voice Assistant

- Speech Recognition
- Text-to-Speech
- Automatic voice mode
- Manual voice mode
- Interruptible speech

### 🌐 AI Browser

- AI-powered search
- Summarised answers
- Markdown responses
- Backend API

### 🎨 Rendering Engine

- Custom GLSL shaders
- Three.js
- React Three Fiber
- GPU-powered effects

## 🚀 Installation

### Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn main:app --reload
```

### Frontend

```bash
cd frontend

npm install

npm run dev
```
